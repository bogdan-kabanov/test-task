# TestApp

Мобильное приложение на React Native (Expo SDK 56) с подпиской на музыку.

## Стек технологий

- **React Native** 0.85 + **Expo** 56
- **expo-router** — файловая навигация
- **Zod** — валидация данных
- **AsyncStorage** — локальное хранение состояния покупки
- **TypeScript** 6

## Архитектура

Проект построен по методологии **Feature-Sliced Design (FSD)**:

```
src/
├── shared/          # Переиспользуемые модули
│   ├── lib/         # Утилиты и сервисы
│   │   └── storage.ts   # AsyncStorage + Zod-схема покупки
│   └── ui/          # UI-компоненты
│       └── PrimaryButton.tsx
├── entities/        # Бизнес-сущности
│   └── subscription/
│       ├── model/
│       │   ├── types.ts  # Zod-схемы и типы подписок
│       │   └── data.ts   # Данные карточек подписок
│       └── index.ts
```

## Структура страниц (expo-router)

```
app/
├── _layout.tsx      # Корневой Stack-навигатор
├── index.tsx        # Страница 1 — Приветствие
├── plans.tsx        # Страница 2 — Выбор подписки
└── home.tsx         # Главная — после покупки
```

## Хранение данных

Состояние покупки сохраняется локально через `AsyncStorage`. При повторном входе пользователь автоматически попадает на главную страницу. Данные валидируются через Zod-схему:

```typescript
const PurchaseSchema = z.object({
  purchased: z.boolean(),
  plan: z.enum(['monthly', 'yearly']).nullable(),
  purchasedAt: z.string().nullable(),
});
```

## Conventional Commits

Проект использует Conventional Commits на русском языке:

- `feat:` — новая функциональность
- `fix:` — исправление ошибок
- `chore:` — настройка, зависимости, конфигурация
